# 「フロストスー」・ Building Tools for Tinkerers, by a Tinkerer

> 夜の作業室 (Nocturnal Workspace) &mdash; Crafting automation engines, network utilities, and interactive software for power users.

I am a software developer, system tinkerer, and automation enthusiast. I build event-driven Telegram bots, network proxies, reverse-engineering utilities, and AI-assisted workflows designed with precision and simplicity.

---

### Featured Works

- [**TG2XPoster**](https://github.com/FrostSue/TG2XPoster) &mdash; Real-time event-driven automation engine mirroring Telegram channel content to X (Twitter) with zero latency, group media support, and Docker ready.
- [**Phone-Tether-Tunnel**](https://github.com/FrostSue/Phone-Tether-Tunnel) &mdash; Low-level proxy router sharing mobile VLESS VPN tunnels with PC over USB/Hotspot, enabling full UDP and Discord voice routing.
- [**Anime-Sage-Telegram-Bot**](https://github.com/FrostSue/Anime-Sage-Telegram-Bot) &mdash; High-performance recommendation bot powered by Pyrogram and Groq AI (Llama 3) with asynchronous architecture.
- [**LinguaDash**](https://github.com/FrostSue/LinguaDash) &mdash; Fast-paced vocabulary game built with Flutter and Dart featuring custom word pools and low-latency audio.
- [**Free-UAV-Forecast**](https://github.com/FrostSue/Free-UAV-Forecast) &mdash; UAV pre-flight meteorology and geomagnetic storm alert platform.
